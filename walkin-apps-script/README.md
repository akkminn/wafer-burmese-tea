# Walk-in storage script

`Code.gs` is a **separate** Apps Script deployment for staff walk-in sales. It does not replace or modify the existing pre-order endpoint.

Follow [the full setup guide](../docs/walk-in-setup.md) to create the three worksheets, set Script Properties, deploy the web app, and connect the Vercel Functions. Do not paste the shared secret into React or a `VITE_` variable.
